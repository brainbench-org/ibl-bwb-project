# ibl-bwb project page

The public project page for [IBL BrainWideBench](https://github.com/brainbench-org/ibl-bwb),
live at <https://brainbench-org.github.io/ibl-bwb-project/>.

A single static `index.html` with inline CSS: edit it, push to `main`, and GitHub
Pages redeploys from the branch. Remaining placeholders are marked `TODO`
in the source.
